# Heath18

Weight-loss burn planner. Single file: `index.html`.

- Goal: current / target weight, target date, daily burn
- Plan: fasts per week, clean-day deficit, water before meals
- Shows total kcal to burn (1 kg ≈ 7,700 kcal), fasts and clean days needed
- History calendar with streaks

Live: https://health18.vercel.app
